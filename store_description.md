# Short Description
Mouse Gestures with visual feedback for effortless browser navigation.

# Detailed Description
Mouse Gestures is an extension that lets you navigate your browser using simple mouse movements. With real-time visual feedback, you see exactly what gesture you're drawing.

Main Purpose: Efficient browser navigation through intuitive mouse gestures.

Supported Gestures:
• Draw Left (L): Go Back
• Draw Right (R): Go Forward
• Draw Down-Right (DR): Close Tab
• Draw Up-Right (UR): Reopen Closed Tab

Key Features:
• Visual feedback with color gradients
• Configurable activation button (right mouse button by default)
• Easy gesture cancellation
• Automatic settings persistence

Required Permissions Explained:
• sessions: Enables the "reopen closed tab" feature
• storage: Saves your gesture settings between browser sessions

Privacy & Data Usage:
• Mouse movement is only tracked while drawing gestures
• All tracking data is temporary and immediately discarded after drawing
• No personal data is collected or stored
• No browsing history or website content is accessed
• Settings are stored locally in your browser only

External Code Usage:
• Chota CSS (v0.9.2): A lightweight CSS framework used only in the settings popup for consistent and responsive UI design. Source: https://cdn.jsdelivr.net/npm/chota@latest/dist/chota.min.css
